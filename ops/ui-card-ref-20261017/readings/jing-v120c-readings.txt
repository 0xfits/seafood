【3】三臂实测读数（同一 dist · 同一 headless Chrome · Kong 2026-10-17）
--------------------------------------------------------------------------------
命中元素 class = `dark:bg-gray-800` / `dark:text-yellow-400`（**既有产物类，非本单新增**）

  臂 A：站点夜档（html[data-theme]=dark）+ 设备偏好 light
        · matchMedia('(prefers-color-scheme: dark)').matches = **false**
        · html 计算值 color-scheme = **dark**
        · dark:text-yellow-400 回读 = **rgb(250, 204, 21)**   ← #FACC15
        · dark:bg-gray-800     回读 = **rgb(31, 41, 55)**     ← #1F2937
        ⇒ **dark: 工具类生效**
  臂 B：站点夜档 + 设备偏好 dark（mqDark = true）
        · 同上两值（rgb(250,204,21) / rgb(31,41,55)）⇒ **同样生效**
        （⇒ 生效与否**不由设备偏好决定**）
  臂 C（控制臂）：**同一设备偏好（light）下只把 data-theme 翻回 light**
        · html 计算值 color-scheme = light
        · dark:text-yellow-400 回读 = **rgb(0, 0, 0)**
        · dark:bg-gray-800     回读 = **rgba(0, 0, 0, 0)**
        ⇒ **失效**（回落到无 dark: 的外观）
        · 臂 C 相对臂 A/B **两键取值皆变**（`armC_changed_vs_armA` 两键均 true）
        ⇒ **尺子灵敏度已自证**（不是「恒绿」）
